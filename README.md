# 🎓 Student Exam Score Prediction App

This is a Streamlit app that predicts a student's **exam score** based on habits, attendance, sleep, mental health, and other features.

---

## 🔗 Live Demo

[https://hassan9255-student-score-prediction-app-lo6er5.streamlit.app/](https://hassan9255-student-score-prediction-app-lo6er5.streamlit.app/)

---

## 📚 Dataset

The data for this project comes from Kaggle:  
[Student Habits vs Academic Performance](https://www.kaggle.com/datasets/jayaantanaath/student-habits-vs-academic-performance)

---

## 🛠️ Features & Workflow

- Load dataset and explore data (missing values, duplicates, descriptive stats)  
- Visualize distributions, correlations, and relationships  
- Encode categorical variables  
- Train multiple regression models (Linear, Decision Tree, Random Forest) with hyperparameter tuning  
- Select best model using RMSE / R²  
- Save best model using `joblib`  
- Build Streamlit interface to take user inputs and show predictions
